# Build Lagun Lab website

## Scope
- Create the complete public site: Home, Research, Cognitive Drive Architecture, Projects, People, Publications, Join, About, Policies, Open Science, and Contact.
- Use the selected Editorial Index direction with the Paper & Forest palette and IBM Plex Sans.
- Keep all claims academically cautious and show honest empty states where verified projects, publications, links, dates, or identifiers are unavailable.

## Content and experience
- Present research first, followed by projects, people, outputs, institutional policies, and participation.
- Build structured collections for projects, people, and publications so verified records can be added later.
- Add responsive navigation, accessible page structure, project progress indicators, filters, and separate application/collaboration forms.
- Route form submissions to a clearly marked placeholder institutional email rather than displaying false confirmation.

## Technical details
- Use TanStack Start routes and shared React components.
- Define the selected brand colors as semantic Tailwind v4 tokens.
- Give every public page unique title, description, OpenGraph metadata, and canonical URL.
- Verify desktop and mobile layouts, navigation, form validation behavior, and preview health.
